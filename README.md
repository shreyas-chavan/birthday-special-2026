# Sweek — A Little Magic

A self-contained static birthday website designed for GitHub Pages.

## Included
- Alohomora password gate at the landing page.
- Decorative Hogwarts-inspired parchment letter.
- Supplied Sorting Hat image and Gryffindor crest.
- Slow Sorting Hat sequence with readable pauses.
- Sorting resets after leaving the section.
- Photo memory timeline + masonry gallery.
- Interactive personality cards.
- Distance chapter reflecting 2022 onward and the farther distance in 2026.
- Final birthday message.
- No video required.

## Important privacy/security note
GitHub Pages is public. The `alohomora` gate is an experience/interaction, not real security. The photos and page source remain publicly accessible to anyone who has the site URL.

## Deploy
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets/` folder.
3. In GitHub: Settings → Pages → Deploy from branch → select `main` and `/root`.
4. Open the generated Pages URL.

All photos are stored locally in `assets/`, so no external photo hosting is required.
